Ruta del español

Seventeen Spanish pages in a suggested order: two reference pages, then fifteen dialogues that start in English and end in Spanish. Later dialogues reuse some earlier words, and each page starts its pronunciation guides fresh.

How to use each page

  1. Play each line before you read its pronunciation guide, then say it aloud.
  2. Read it again with guides off. Tap only the words you lose.
  3. Read the final stage out loud before playing it, then compare. Try "Listen first" and the "Check yourself" quiz on each stage.
  4. The next day, replay the last stage with guides off before you open a new page.
  5. Keep Lo básico and Español de trabajo open in other tabs and look things up as you go.
